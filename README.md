# Monitor-de-Separa-o-BOPIS-Alertas-WhatsApp
Script em Python para execução agendada (Databricks) responsável por monitorar pedidos do tipo BOPIS (Buy Online, Pick Up In Store) pendentes de separação nas lojas físicas, consultar a disponibilidade de estoque local e despachar alertas formatados para grupos operacionais de WhatsApp via webhook do n8n.
